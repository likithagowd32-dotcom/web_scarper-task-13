# Task 13: Web Scraping Using BeautifulSoup

# Project Description
This project demonstrates web scraping using Python.  
The program collects data from a legal website, parses HTML content using BeautifulSoup, and stores the extracted information into a CSV file.

The project is developed as part of an internship/academic assignment to understand basic web scraping concepts.



#Tools & Technologies Used
- Python
- requests library
- BeautifulSoup (bs4)
- VS Code
- CSV file handling

#Website Used
- "https://www.geeksforgeeks.org/"

(This website is publicly available and safe for learning web scraping.)
